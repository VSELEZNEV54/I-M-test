# с?м — кликабельный прототип интернет-магазина

Интерактивный прототип интернет-магазина стритвир-бренда **«с?м» («сколько можно?»)** по техническому заданию.
Чистая статика: HTML + CSS + vanilla JS, без сборщиков и зависимостей — открывается где угодно и размещается на GitHub Pages как есть.

> Все товары, фото, заказы, клиенты и цены — демонстрационные. «Оплата», «уведомления» и интеграции эмулируются. Изменения (корзина, избранное, заказы, правки в админке) сохраняются в localStorage вашего браузера.

## Что внутри

**Витрина** — главная (промо, коллекции, хиты, новинки, акции, блог, SEO-текст), каталог с фильтрами/сортировкой/поиском/«показать ещё», карточка товара (галерея, размеры, остатки, related, недавно просмотренные, JSON-LD), избранное, корзина с промокодами (`SKOLKO15`, `MOZHNO500`, `BUNT10`), оформление заказа в 3 шага, страница «заказ оформлен».

**Личный кабинет** — вход (демо: любые данные или кнопка «войти демо-пользователем», код из смс `0000`), профиль, мои заказы со статус-треком и «повторить заказ», спецпредложения, адреса доставки.

**Контент** — блог со статьями (таблицы, списки, товарные блоки), «о бренде», лукбуки, доставка и оплата, возврат, контакты, юридические страницы, 404.

**Админ-панель** (`/admin/`, ссылка в верхней плашке сайта) — dashboard с метриками и графиком продаж, база заказов (таблица + канбан с drag-and-drop, история изменений), карточка заказа, товары (массовые действия, экспорт CSV), редактор товара с живым превью, импорт CSV с проверкой ошибок построчно, категории, клиенты, промокоды и акции, блог и страницы, настройки (оплата, доставка, шаблоны уведомлений, роли, SEO).

## Сброс демо-данных

Прототип запоминает состояние в браузере (корзина, избранное, созданные заказы, правки каталога).
Чтобы вернуть всё в исходный вид перед показом клиенту — в админ-панели, внизу левого меню: **↺ сбросить демо-данные**.

## Как посмотреть локально

```bash
npx serve .
```

или любой другой статический сервер из корня проекта (для file:// тоже работает, но лучше сервером).

## Как выложить на GitHub Pages

1. Создайте репозиторий и запушьте содержимое этой папки в ветку `main`.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Все пути в проекте относительные, поэтому прототип работает из любой подпапки.

## Структура

```
index.html, catalog.html, product.html, cart.html, checkout.html, …
admin/            — админ-панель (index, orders, order, products, …)
assets/css/       — main.css (дизайн-система), admin.css, стили страниц
assets/js/        — data.js (демо-данные), store.js (состояние), ui.js (общий хром), логика страниц
assets/img/       — фотографии товаров и съёмок
```

Дизайн — по референсам MOON (Figma): фирменные логотипы бренда (`assets/img/brand/`), единственная гарнитура **Manrope** (Google Fonts), кислотный лайм `#c6db1f`, слива `#83517b`, всё строчными.

Логотипы: `logo.svg` / `logo-dark.svg` / `logo-white.svg` — компактный знак с?м® (в шапке, подвале и админке вставляется инлайном и наследует цвет текста), `logo-full-*.svg` — полный лок-ап «сколько? можно®» (герой главной и страницы «о бренде»).
